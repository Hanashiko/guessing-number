# 🎯 Guessing Number Game

Це проста консольна гра, написана на Python, де гравець повинен вгадати випадкове число в заданому діапазоні.

## 📌 Опис

Програма генерує випадкове число від `1` до `9` (включно), а користувач намагається вгадати його. Після кожного введення користувача гра підказує, чи потрібно вводити більше або менше число. Гра триває, доки не буде вгадано правильне число.

## 🛠️ Використані технології

- Python 3
- Вбудований модуль `random`

## 🚀 Як запустити

1. Скопіюй код у файл, наприклад `main.py`
2. Запусти через Python:

```bash
python main.py
```
